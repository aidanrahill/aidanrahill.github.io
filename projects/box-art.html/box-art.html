Box Art

Puzzle Game & Optimal Level Solver · February 2026 – Present

Coming Soon

The full project page for Box Art is coming soon. Check back for a playable demo, level examples, and more details about the game and its optimal level solver.

Built the game in Godot 4 using signal-driven managers, quaternion-based cube rotation with slerp-animated, drag-controlled rolls, and stack-based undo/reset history. The solver finds the minimum number of moves for any level using A* search, and was verified against a brute-force search on 4,000+ random levels.
